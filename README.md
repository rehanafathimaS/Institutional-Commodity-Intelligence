# 📈 Institutional Commodity Intelligence Platform

An end-to-end Machine Learning web application to analyze and forecast global commodity prices (Grains, Energy, Metals, Oils & Meals) using interactive analytics and predictive modeling.

## 🚀 Live Demo
https://institutional-commodity-intelligence-rxlupjnjna5bs6q27grnbb.streamlit.app/

## 🛠️ Features & Highlights
- **Interactive Visualizations:** Historical price trends, market share distribution, and monthly price averages powered by Plotly.
- **ML Forecasting Pipeline:** Predictive models saved via `pickle` (`commodity_model.pkl`, `scaler.pkl`) for dynamic price projections.
- **Custom UI:** Dark-themed responsive dashboard built with Streamlit.

## 🧰 Tech Stack
- **Languages & Frameworks:** Python, Streamlit
- **Data & ML:** Pandas, NumPy, Scikit-Learn
- **Visualization:** Plotly Express & Graph Objects
- **Version Control:** Git & GitHub

## 📂 File Structure
- `app.py`: Streamlit multi-page layout and visualization dashboard.
- `train_model.py`: Data preprocessing and model training script.
- `commodity_model.pkl` / `scaler.pkl`: Serialized model and feature scaler artifacts.
- `requirements.txt`: Project dependencies for seamless cloud deployment.
